# Search and saved studies

Design: retain cream #fff6d7, paper #fffbee, lavender #dda9ef, yellow #f8ed94 and ink #2d2333; existing local Montserrat and Caveat. Add a compact left-aligned labeled search form beside a Saved studies shortcut. Keep the large DNA as the primary visual. Search results reuse the existing artwork grid and wrapping topic links. Saved controls are adjacent to, never nested inside, artwork links. No new decorative animation.

Search uses bounded URL queries and the existing public content/graph, including topic labels. Multiple search words must all match. Concept filters retain the query; detail, related and previous/next navigation preserve return context. Unknown filters recover gracefully; empty search results offer a reset and clear guidance. Search works through server-rendered GET forms and links.

Saved studies use a versioned browser-local list of artwork IDs, with no account or server write. The shelf shows only currently public adapter records. Buttons use aria-pressed and communicate state. A hydration/loading state avoids a false empty shelf. Browser-storage denial falls back to memory until reload with an explicit notice. Cross-tab storage events refresh state; normal updates read the current value before writing. Simultaneous writes are best effort, not transactional. No bulk deletion, cloud sync, private content, or external dependency.
